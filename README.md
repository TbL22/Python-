# CampusPocket 校园账本

## 第四版：第4章字典与集合

运行：

```powershell
python CampusPocket/chapter04.py
```

无需输入，直接显示题目规定的4条消费记录。每条记录用字典保存日期、类别、金额和备注，再用列表保存多条记录。集合用于去除重复类别，`totals.get()` 用于按类别汇总。

代码按题目要求使用字典、列表、集合、`get()` 和基础 `if` 判断，没有提前使用循环、自定义函数、类或第三方库。四条汇总语句按要求分别写出，第5章学习循环后再简化。

预期：4条记录，3个不重复类别；餐饮26.5元、交通2.0元、学习12.0元，总额40.5元。餐饮占65.4%，是金额最多的类别，汇总合计与总额相等。

集合打印时的类别顺序可能不同，但其中的三个类别相同，符合去重要求。
