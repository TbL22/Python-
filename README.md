# CampusPocket 校园账本

课程贯穿项目：第 1—9 章逐章完善，始终使用一个 GitHub 仓库。

## 本次交付：第 2 章（首次收到的作业要求）

命令行输入一笔消费和月度预算，输出剩余金额、已用比例以及三档提醒：

- 小于 80%：预算充足。
- 80% 到 100%（含两端）：接近或已用完预算。
- 大于 100%：超出预算。

已完成三个选做项：金额显示两位小数、百分比显示一位小数；判断是否为整数元；计算余额还够支付多少笔同额消费。

## 运行

在当前项目文件夹打开终端，执行：

```powershell
python main.py
```

依次输入消费和预算，例如 25、100。结果为余额 75.00 元、已用 25.0%，还能支付 3 笔同额消费。

金额单位为元，最多两位小数；消费不能为负，预算必须大于零。无效输入会提示并退出，可以重新运行。零元消费不计算有限笔数。超过预算时余额为负，可再支付笔数为 0。

## 本章知识对应

- `input`、`float`：输入和类型转换。
- 变量、减法、除法：余额和已用百分比。
- `if / elif / else`：三档预算提醒。
- f-string 的 `.2f`、`.1f`：显示格式。
- `%`、`//`：整数元判断及可再消费笔数。
- 补充保护：`try / except` 处理错误输入，`math.isfinite` 拒绝无穷大和非数字值。

内部用整数分计算，避免例如 0.30 元预算、0.10 元消费时整除误少算一笔。
