## 运行验收

| 消费 / 预算 | 预期 |
| --- | --- |
| 25 / 100 | 余额 75.00，已用 25.0%，低档，还能 3 笔，是整数元 |
| 80 / 100 | 中间档 |
| 100 / 100 | 中间档，余额 0.00 |
| 120 / 100 | 高档，余额 -20.00，还能 0 笔 |
| 79.99 / 100 | 低档；显示可能舍入为 80.0%，判断仍按真实金额 |
| 100.01 / 100 | 高档 |
| 0.10 / 0.30 | 余额 0.20，还能 2 笔，不是整数元 |
| 0 / 100 | 提示不计算还能消费的笔数 |

## 课后思考参考

1. 容易出错的是输入类型转换、80% 和 100% 的边界以及小数运算。应先将输入转为数字，明确两个边界都属于中间档。计算同额消费笔数时先换算成整数分，可以避免整除受到浮点误差影响。
2. 数据增多后，可在后续章节用列表保存多笔消费，再学习循环统一处理；本章仍只处理一笔。
