# CampusPocket 校园账本

## 第三版：第3章序列

运行：

```powershell
python CampusPocket/chapter03.py
```

无需输入，直接显示题目规定的5笔消费、最近3笔、笔数、总额和平均值。选做部分包括金额前三名、最大和最小消费对应的项目名，以及每2元一个方块的条形图。

代码使用列表、索引、切片、len、sum、sorted、max、min、index、ljust及基础运算，没有循环、自定义函数、类或第三方库。条形图暂写5行，学到循环后再简化。

预期：5笔，总额65.50元，平均13.10元；最近3笔为打印资料、奶茶、社团聚餐；金额前三名25.0、18.5、12.0；最大为社团聚餐，最小为校园公交。

题目要求金额保留两位小数，但示例只显示一位。本版统计值、单笔及图表金额显示两位小数；直接打印的金额列表保留Python默认表示。ljust(6)按字符数补空格，中文在不同终端中的显示宽度可能不同。

实验报告见 `reports/chapter03/实验报告.md`。
